# Francesco Dessabo — Portfolio starter

A cinematic, responsive portfolio starter built with Astro.

## Requirements
- Node.js 20.3.0 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Astro (usually http://localhost:4321).

## Build
```bash
npm run build
npm run preview
```
The production website is generated in `dist/`.

## Deploy to Cloudflare Pages
1. Push this project to a GitHub repository.
2. In Cloudflare, create a Pages project and connect the repository.
3. Use `npm run build` as the build command.
4. Use `dist` as the build output directory.
5. Cloudflare will provide a `*.pages.dev` preview address.

## First things to customise
- Replace the showreel placeholder in `src/pages/index.astro` with your showreel embed or video.
- Replace the three sample project cards with real projects.
- Rewrite the About section in your own voice.
- Update the contact email address.
- Replace the placeholder visuals with approved project stills.

This starter deliberately uses placeholders rather than inventing project credits or embedding copyrighted campaign footage.
